На главном экране после подключения — кнопки «Переключить» (сразу на самый быстрый из запасных, как в уведомлении) и «Найти заново» (полный поиск)
Карточка «Сервисы через этот узел»: проверка Gemini, ChatGPT, Claude, YouTube и своего адреса через текущее подключение — с причиной, если не открылось. Можно включить проверку сразу после подключения
Новые способы находить подписки. Вставьте ссылку на репозиторий GitHub — «Лоцман» сам найдёт в нём файлы с ключами (через jsDelivr, работает и когда GitHub недоступен). Вставьте публичный Telegram-канал (t.me/канал) — ключи соберутся из его постов и будут обновляться как подписка
Подписка-страница: если по ссылке вместо списка пришла веб-страница с ключами, ключи берутся прямо из неё
Каталог теперь сам ищет свежие подписки поиском по GitHub (репозитории, обновлённые за последние дни) — найденные проходят ту же проверку на безопасность и живость
